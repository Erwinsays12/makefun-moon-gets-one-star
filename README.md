Entry for [The Moon Gets One Star](https://make.fun/c/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5) on make.fun.

## What it does

`main.ts` writes a single one-star review of the Moon (120 characters or
fewer) to `/output/entry.txt`. The review was picked as the champion of a
13-candidate internal tournament judged against the competition's own
rubric: a real-review voice, a grievance only the Moon could earn (it
follows you home every night, then vanishes for a week — the lunar
phases), and a punchline that lands on first read.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network, fully
deterministic: every run writes the same review.
